# wicked-estate-rank

PageRank symbol-importance ranking for [wicked-estate](https://github.com/mikeparcewski/wicked-estate).

Runs PageRank over the resolved call/use graph so the most-important symbols (orchestrators, entry points, high-leverage programs) surface first in retrieval and analysis. Deterministic and dependency-light.

Part of **[wicked-estate](https://github.com/mikeparcewski/wicked-estate)** — a code + infrastructure
estate graph for LLM agents (definitions, who-calls-X, blast-radius, scoped context). Local-first,
tree-sitter + SQLite, single static binary. See the umbrella [`wicked-estate`](https://crates.io/crates/wicked-estate)
crate to use the whole thing.
